# 05 — Spesifikasi UI (baca di tahap 07, 09, 10, 11)

Referensi visual & interaksi: `reference/arc-crm-mockup.html` (buka di browser; semua layar, data contoh, dan interaksi ada di sana). Estetika: Apple-like — bersih, card-based, bayangan halus, whitespace, tipografi Plus Jakarta Sans (display) + Instrument Sans (body) + JetBrains Mono (provenance). Design tokens (light/dark) ada di `<style>` mockup: salin ke `apps/web/src/styles/tokens.css`.

## Navigasi (final)
Rail: *Kerja hari ini* → Hari ini (badge keputusan), Chat (badge belum dibaca); *Bisnis* → Relasi, Penjualan, Kas; bawah → Pengaturan. Bilah atas: judul + sub-judul + **view tabs** (Relasi: Daftar akun | Peta koneksi 3D; Penjualan: Pipeline | Prospek & funnel; Pengaturan: 5 tab), kotak **Tanya ARC / cari akun** (⌘K) dengan dropdown pertanyaan kontekstual. Mobile: tab bar 5 item; kotak Tanya selebar layar.

## Layar & komponen
- **Hari ini**: sapaan; status strip (keputusan, komitmen, sinyal, gap); tur 30 detik (dismissible, localStorage); Brief (4 poin, provenance footer, confidence); **Keputusan** = antrean Action dengan filter (Kirim / Kebijakan & kredit / Re-engagement), item terlipat dengan aksi utama di header; Komitmen hari ini; Sinyal baru; kanan: Besok (agenda + status prep), Forecast (commit/best/pipeline vs target), Denyut bisnis, Renewal & ekspansi, baris agen (collapsible).
- **Action sheet** (dipakai di mana pun): provenance line (agen, sumber, confidence, model), Kenapa sekarang, Yang disiapkan (+preview), Setelah disetujui (langkah), tombol Setujui & jalankan / Edit dulu / Tolak (alasan chips + teks) / Nanti, catatan "tidak ada yang terkirim tanpa langkah ini".
- **Chat**: 3 panel (daftar dengan tab Semua/Pelanggan/Grup ekst./Grup int./Internal + judul bagian; thread dengan anotasi ARC di bawah pesan dan tag internal/eksternal pada pengirim grup; panel konteks: akun + next action, ekstraksi, komitmen; untuk grup: project, ringkasan, tugas terdeteksi → Basecamp, anggota). Composer "Balas sebagai <pemilik nomor>" + 3 saran balasan; chat internal pribadi menampilkan penjelasan, bukan isi.
- **Relasi**: daftar akun (health dot, nilai, terakhir); halaman akun dengan anchor bar (Langkah · Ekspansi · Memori · Orang · Deal · Komitmen · Timeline): header (health ring + tren, nilai, interaksi terakhir), Langkah berikutnya, Sistem terpasang & ruang ekspansi (matriks 6 lini), Memori akun (+provenance), Peta stakeholder (SVG radial: garis tebal = intensitas, putus-putus = belum kontak; badge single-threaded), Deal intelligence (stage Odoo + sinyal ARC + breakdown health + flag dengan tombol), Commitment ledger (kami/mereka), Timeline (+apa yang disimpulkan ARC).
- **Peta 3D** (menu sendiri di rail *Bisnis*, juga tab di Relasi, dan versi mini per akun di halaman akun): three.js force-graph dengan **fallback 2D canvas** bila WebGL/CDN tidak tersedia (engine `createNet()` di mockup — satu instance per container); node sales (accent) & kontak (warna health akun, abu = tanpa deal); ukuran = rata-rata pesan/bulan; jarak = kedekatan; filter per sales; periode 30/60/90/180 hari; tooltip; klik fokus, klik lagi buka akun; panel pasangan terkuat & pola koneksi.
- **Penjualan / Pipeline**: bar sinkron Odoo; segmented Pipeline Odoo (kanban stage Odoo, kartu = field Odoo + baris ARC health/sinyal + **langkah berikutnya** dengan tombol) | Medan ARC (scatter health × nilai); panel Odoo vs bukti ARC; Dua cara membaca pipeline; Pola win/loss; Tender radar; Tim & disiplin eksekusi.
- **Penjualan / Prospek & funnel**: funnel 7 tahap + konversi + waktu; sumber & win rate; Nomor baru masuk (skor) + detail (sumber identifikasi, overview, tombol Buat lead / Balas pertanyaan pertama / Bukan prospek), Alternatif solusi (tangga nilai), Pertanyaan pain point (tiap jawaban membuka solusi), Funnel atau flywheel (diagram + 3 metrik + verdict).
- **Kas**: 4 KPI; Won → Lunas per project (5 segmen, hari vs benchmark, tombol tindakan); Umur piutang + tindakan penagihan; Prediksi kas masuk 30 hari (probabilitas dari pola bayar).
- **Pengaturan**: Sumber sinyal (+identifikasi nomor & catatan Getcontact); WhatsApp (mode resmi vs QR, riwayat awal 30–180 hari dengan catatan sumber riwayat, nomor sales, QR, Batas & privasi dengan toggle, grup yang dibaca ext/int); Nomor internal (tabel, form, sinkron Talenta, dugaan ARC); AI & model (MCP server + tool groups + toggle, klien AI, config snippet, routing model, biaya); MCP & API (endpoint, tabel endpoint, curl, API key, Kalibrasi agen + yang dipelajari).

## Prinsip UI
Summary sebelum detail; state dikodekan dalam bentuk (pill/dot/stripe) bukan hanya angka; semua angka `tabular-nums`; satu tombol per saran; provenance selalu terlihat; light & dark; tidak ada tabel yang harus dibaca ke bawah untuk menemukan yang penting.
