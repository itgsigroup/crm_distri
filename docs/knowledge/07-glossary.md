# 07 — Glosarium
BAST — Berita Acara Serah Terima (dokumen serah terima project; syarat invoice). SPK — Surat Perintah Kerja. PPK — Pejabat Pembuat Komitmen (penandatangan di instansi). ULP — Unit Layanan Pengadaan. HPS — Harga Perkiraan Sendiri (pagu tender). SPM — Surat Perintah Membayar (proses bayar pemerintah). DAK — Dana Alokasi Khusus. LPSE — portal tender pemerintah. e-katalog — pengadaan pemerintah via katalog LKPP. SBU — Sertifikat Badan Usaha. Termin — jangka waktu pembayaran (umumnya 30 hari). DSO — days sales outstanding. L2C — lead-to-cash. Champion — kontak di pelanggan yang mendorong deal. Single-threaded — hubungan bertumpu satu orang. Videotron — LED display outdoor besar. VMS — video management system. PTZ — kamera pan-tilt-zoom. Videowall — susunan layar untuk command center.
